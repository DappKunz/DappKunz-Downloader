# MediaDownloader

**A modern Android media downloader.**

Downloader is an Android application project focused on convenient media downloading, with a clean dark interface and futuristic blue accents.

## Features

- Video and audio downloads
- Playlist download management
- Photo and gallery downloads
- Built-in local music player
- Audio equalizer
- Online Music discovery
- Download history and progress tracking
- GitHub Releases-based update checks

*Features are subject to the current implementation and supported sources.*
